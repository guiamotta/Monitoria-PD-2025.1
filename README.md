# Exercícios de Introdução à Programação em Python - Monitoria de Processamento de Dados UFBA

Este repositório contém uma série de listas de exercícios em Python. Turma de Processamento de Dados (MAT045) do prof. Danilo Coimbra e monitor Guilherme A. Motta.

## Conteúdo

### 📘 Lista 1: Definições de Variáveis e Operadores
- Introdução ao uso de variáveis em Python
- Tipos de dados primitivos (inteiros, floats, booleanos, strings)
- Operadores aritméticos (+, -, *, /, %, **)

### 📗 Lista 2: Condicionais (if / elif / else)
- Estruturas de decisão
- Uso do `if`, `elif` e `else`
- Aninhamento de condições
- Expressões booleanas
- Operadores relacionais (==, !=, <, >, <=, >=)
- Operadores lógicos (and, or, not)

### 📙 Lista 3: Laços de Repetição (for / while)
- Uso do `for` com `range()`
- Estruturas de repetição com `while`
- Controle de fluxo com `break` e `continue`
- Contadores e acumuladores

### 📕 Lista 4: Listas
- Criação e manipulação de listas
- Acesso por índice
- Métodos úteis (`append()`, `remove()`, `sort()`, `len()`, etc.)
- Iteração sobre listas

### 📒 Lista 5: Strings
- Manipulação de strings
- Métodos de string (`lower()`, `upper()`, `split()`, `strip()`, etc.)
- Formatação de texto

### 📓 Lista 6: Matrizes
- Criação de matrizes (listas de listas)
- Acesso e modificação de elementos
- Iteração sobre linhas e colunas
